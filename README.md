# 地理クイズAI
本プログラムは、「答えを直接言わず、ヒントのみを提供する学習支援AI」の要件に基づい
て設計された地理クイズAIである。ユーザーに対し、ある都道府県を推測させる形式の問
題を出題し、ユーザーが間違えた場合には正解を言わずに追加のヒントや誤答との違いをや
さしく解説する。正解時には、その都道府県の特徴を褒める形で解説を行うことで、自然な
学習と理解の促進を図る。

## 工夫
本プログラムでは、「答えを直接言わずヒントのみを提示する」という学習支援AIの要件
を満たすために、いくつかの工夫を行った。

まず、出題内容として日本の47都道府県をすべて対象にすることで、学習の幅を広げるよ
うにした。また、ユーザーが地名を推測する過程で自然に知識を深められるよう、各都道府
県の特徴をもとにした「ヒント」を3つ提示する形式とし、それらはGemini APIを用い
て生成している。API に与えるプロンプトには「都道府県名を含めないこと」「100文字以
内で簡潔に」「重複せず異なる視点から提示すること」といった条件を明示し、ユーザーの
想像力を促す質の高いヒントとなるよう工夫している。

ユーザーが不正解だった場合には、ただ正解を伝えるのではなく、誤って選んだ都道府県と
正解の都道府県の違いを、Gemini によってやさしく解説する仕組みを取り入れた。これに
より、ユーザーは自らの誤認の理由を理解し、次の問題に活かすことができる。また、正解
時には該当する都道府県の特徴を褒める形式で伝えることで、知識の定着と学習意欲の向上
を図っている。

さらに、AIのペルソナとして「博士」という落ち着いた男性像を設定し、安心感と信頼感
のあるナビゲートを行えるよう設計した。全体を通して、単なるクイズではなく、間違いを
通じて理解を深め、正解で自信を得られるような対話型の学習支援体験を目指している。
